# Espelho de contingência — Eleições no Terra

Este repositório publica uma cópia estática, somente de leitura, do último snapshot oficial preservado pelo Buscador de Candidaturas.

Os arquivos `index.html` e `data.json` são gerados a partir da base oficial sincronizada do TSE. O espelho não aceita contribuições de dados, não consulta fontes alternativas e não substitui a rotina diária do site principal.

Em uma indisponibilidade do buscador principal, este endereço alternativo permite consultar as candidaturas e os documentos de proposta que já constavam no snapshot oficial.
